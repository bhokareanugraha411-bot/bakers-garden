# Bakers Garden — Premium Website

A long, responsive, Gen-Z-inspired static website for Bakers Garden, Malkapur/Karad.

## Included
- Premium animated landing page
- Mobile + desktop responsive layout
- Cakes / celebrations sections
- Photo gallery using the supplied photos
- Menu section using the supplied menu image + transcribed prices
- Instagram, WhatsApp, phone and order buttons
- Google Maps directions button
- Animated ticker, floating objects, hover effects and scroll reveals
- No framework/build step required

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the entire `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch → main → /(root) → Save.
4. Open the generated GitHub Pages URL.
